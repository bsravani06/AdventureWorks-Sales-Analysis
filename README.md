# AdventureWorks Sales Analysis

## Project Overview

This project focuses on analyzing AdventureWorks sales data to generate meaningful business insights using data analytics and visualization tools.

The project involves data preparation, SQL-based business analysis, and interactive dashboard development to understand sales performance, customer behavior, product performance, and profitability.

## Project Objectives

- Analyze overall sales performance.
- Understand customer purchasing patterns.
- Identify top-performing products.
- Analyze sales trends over time.
- Evaluate production costs and profitability.
- Analyze sales performance across different territories.
- Present business insights through interactive dashboards.

## Tools & Technologies

- **Microsoft Excel:** Data preparation, analysis and dashboard creation.
- **SQL:** Data cleaning, data preparation, calculations and business analysis.
- **Power BI:** Data modeling, DAX and interactive dashboard development.
- **Tableau:** Data visualization and interactive dashboard development.

## Project Structure

### 1. Excel
Contains the Excel-based AdventureWorks sales analysis and dashboard.

### 2. SQL
Contains SQL scripts covering data preparation, product and customer analysis, sales calculations, profitability analysis and business performance analysis.

### 3. Power BI
Contains the Power BI dashboard developed to visualize AdventureWorks sales data and business performance.

### 4. Tableau
Contains the Tableau workbook and interactive sales visualizations.

## SQL Analysis

The SQL analysis covers:

- Data preparation and combining datasets.
- Product and customer information analysis.
- Unit price and sales amount calculations.
- Production cost and profit calculations.
- Sales analysis.
- Sales performance analysis.

The analysis uses the following tables:

- Sales
- DimProduct
- DimCustomer
- DimDate
- DimSalesTerritory

## Conclusion

This project demonstrates the practical application of data analytics tools to transform raw business data into meaningful insights. By using Excel, SQL, Power BI and Tableau, the project provides a structured approach to analyzing sales performance, understanding business trends and supporting data-driven decision-making.
